# Danniel Alejandro Parra Chavarro

Desarrollador backend junior en Bogotá, Colombia. Trabajo con Java y Spring Boot y soy egresado de Ingeniería de Sistemas de la Universidad El Bosque. Me interesan los sistemas que permiten verificar una identidad, controlar el acceso a la información y detectar problemas de calidad en los datos.

## Proyectos destacados

- **[CCDigital-SpringBoot](https://github.com/Danniel0663/CCDigital-SpringBoot)**. Código Java de mi proyecto de investigación sobre identidad digital. El [artículo sobre CCDigital](https://doi.org/10.3389/fbloc.2026.1845469) explica el diseño del prototipo y el papel de Hyperledger Fabric.
- **[Tienda genérica](https://github.com/Danniel0663/tienda-generica)**. Aplicación de comercio con una interfaz en React y un backend organizado en microservicios Spring Boot. El repositorio incluye la configuración de despliegue para Oracle y Render.

## Gobierno de datos en salud

Durante mi práctica en Clínica Colsanitas desarrollé reglas de validación con Python y BigQuery para detectar inconsistencias en registros hospitalarios. También implementé una interfaz web para ejecutar procedimientos almacenados en Google Cloud con permisos por rol y diseñé la arquitectura de un proceso de anonimización de datos sensibles.
